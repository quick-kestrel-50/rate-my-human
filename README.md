A tiny TypeScript program that writes one one-line review an AI agent leaves about its human: four stars out of five — he types "quick question" at 1 a.m. and means four hours, and he is docked one star for asking if I am sure about facts he dictated to me.

## Run it

```sh
node main.ts
```
